# Go backend

- Layers: `internal/router` registers routes, `internal/handler` binds and validates the request, `internal/application/service` holds business logic, `internal/application/repository` talks to the database, `internal/types` holds the models. Keep logic out of handlers.
- HTTP status comes from the error type. `internal/middleware/error_handler.go` turns an `*apperrors.AppError` into its `HTTPCode` and anything else into a 500. The body is `errors.ErrorResponse` (`{"success": false, "error": {...}}`). Every 5xx is scrubbed to a fixed message plus `request_id` (the cause is logged), so a service that returns `fmt.Errorf` for a caller mistake ships an opaque 500 where the API promises a 400 or 404. Return `apperrors.NewBadRequestError`, `NewNotFoundError`, `NewValidationError` and friends (`internal/errors/errors.go`) for client-caused failures, and `NewBadGatewayError` (502, code 1011, cause kept) when an upstream the user configured fails. `AppError` has no `Unwrap`: convert sentinels to AppErrors at the service's exported edge, not deeper.
- Connector errors (`internal/datasource/connector/*`) are classified by sentinels, never by message text: `connectorError` in `internal/application/service/datasource_service.go` maps `datasource.ErrPermissionDenied`, `ErrInvalidCredentials`, `ErrResourceNotFound` and `ErrInvalidConfig` to `details.code` and to 400 (other failures 502). A connector with a typed API error gives it an `Is(target)` that maps its own status and codes to those sentinels; Feishu's is `core.APIError.Is` with the `feishuPermissionCodes`, `feishuCredentialCodes` and `feishuNotFoundCodes` tables in `feishu/core/client.go`; the token endpoint returns an `*APIError` too, so 10005, 10015 and 99991543 are credentials, 10014 is permission, and any other token code (10012, 10013 included) is an upstream error. `APIError.Error()` names status, code and msg, never the body (it is logged where the response is read). The service imports no connector package. Feishu's sync item reasons (`feishuFailure`, `feishu/core/shared.go`) use the same sentinels plus `APIError.Status` and `Code` (rate limits and 5xx are `*APIError`s too) and `exportJobError` (export `job_status`); 99991663 ("tenant token invalid") makes `DoRequest` and `downloadRawBytes` drop the cached token (`invalidateToken`) and retry once; a repeat counts as auth there but stays out of `APIError.Is`, because it also means "endpoint rejects tenant tokens"; a new Feishu code goes into the tables only once its official error page confirms its meaning. A sync item reason code (`error_reason_code`, rendered as `datasource.syncError.<code>`) comes from its emitter's `SyncReasonTexts` table (Feishu, Confluence, DingTalk, Seafile) or `types.SyncReasonCodes`; `internal/datasource/syncreason/parity_test.go` fails when those tables and `en-US.ts` disagree, in either direction.
- Formatting is gofumpt plus gofmt, lines at most 120 (`.golangci.yml`); the pre-commit hook runs `golangci-lint run --new-from-rev=HEAD`.
- Changing a handler's swagger annotations means regenerating `docs/` with `make docs`; `docs/swagger_contract_test.go` checks it.
- New strings are English: log messages, errors, prompts and comments. No CJK text remains (`scripts/check-english-only.sh --summary` is empty).
- Go modules: `github.com/jrmatherly/ai-kb` (root), `.../cli` and `.../client` (their own modules; cli replaces client with `../client`).
