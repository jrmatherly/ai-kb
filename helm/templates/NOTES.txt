  ACCESSING AI KB
--------------------------------------------------------------------------------

{{- if .Values.ingress.enabled }}
AI KB is accessible via Ingress:

  URL: {{ if .Values.ingress.tls.enabled }}https{{ else }}http{{ end }}://{{ .Values.ingress.host }}
{{- if .Values.website.enabled }}
  Docs: {{ if .Values.ingress.tls.enabled }}https{{ else }}http{{ end }}://{{ .Values.ingress.host }}/docs/
{{- end }}

{{- else }}

To access AI KB, use port-forwarding:

  # Frontend (Web UI)
  kubectl port-forward svc/{{ include "ai-kb.serviceName" (dict "component" "frontend" "context" .) }} -n {{ .Release.Namespace }} 8080:80

  # Then open: http://localhost:8080

{{- end }}

{{- if not .Values.ingress.enabled }}

To expose AI KB externally, enable Ingress:

  helm upgrade {{ .Release.Name }} ./helm \
    --set ingress.enabled=true \
    --set ingress.host=ai-kb.example.com

{{- end }}

--------------------------------------------------------------------------------
  CONNECTING TO LLM
--------------------------------------------------------------------------------

Chat and embedding models are added in the web UI (Settings > Model Management).
To use a local Ollama, point the app at it:

  helm upgrade {{ .Release.Name }} ./helm \
    --set app.extraEnv[0].name=OLLAMA_BASE_URL \
    --set app.extraEnv[0].value=http://ollama:11434

Supported LLM backends:
  - Ollama (local)
  - OpenAI API compatible endpoints
  - Qwen, DeepSeek and other hosted providers

{{- if .Values.neo4j.enabled }}

--------------------------------------------------------------------------------
  GRAPHRAG (KNOWLEDGE GRAPH)
--------------------------------------------------------------------------------

Neo4j is enabled for GraphRAG feature.

To use GraphRAG, enable Neo4j. NEO4J_ENABLE is the sole graph switch and is
injected automatically when neo4j.enabled=true (no need to set ENABLE_GRAPH_RAG,
which is deprecated and no longer read by the app):

  helm upgrade {{ .Release.Name }} ./helm \
    --set neo4j.enabled=true \
    --set neo4j.password=<your-secure-password>

Access Neo4j Browser:
  kubectl port-forward svc/{{ include "ai-kb.serviceName" (dict "component" "neo4j" "context" .) }} -n {{ .Release.Namespace }} 7474:7474 7687:7687
  # Open: http://localhost:7474

{{- end }}
