# Brand marks

Third-party logos in this directory, where each came from and the terms it was taken under. A mark is copied verbatim from the owner's brand kit, never redrawn.

| File | Mark | Source | Terms |
| --- | --- | --- | --- |
| `datasource-github.svg` | GitHub Invertocat, black | `GitHub_Invertocat_Black.svg` in `GitHub_Logos.zip` from <https://github.com/logos> (2026-10-22) | Black or white only, no effects, not over busy backgrounds, not rearranged; the standalone Invertocat is for surfaces where the GitHub brand is already established. |
| `datasource-bitbucket.svg` | Bitbucket app logomark (tile) | `Bitbucket_icon.svg` in `bitbucket_app.zip` from <https://atlassian.design/foundations/logos> (2026-10-22) | Keep the tile's radius and colors, no extra container around it, breathing room around it, alt text "Bitbucket". |
| `datasource-onedrive.svg` | AI KB cloud tile | Drawn for AI KB (2026-10-23); no Microsoft asset | Original art. Microsoft's trademark guidelines (<https://www.microsoft.com/en-us/legal/intellectualproperty/trademarks/usage/general>, read 2026-10-23) say its "logos, app and product icons ... can never be used without an express license", and the Microsoft 365 architecture icon set is licensed for "architectural diagrams, training materials, or documentation" only, so no published kit covers a product UI. The product name beside the tile is the truthful compatibility statement. |
| `datasource-sharepoint.svg` | AI KB site page tile (slate, white page glyph) | Drawn for AI KB (2026-10-23, redrawn the same day so it does not echo the SharePoint mark's teal circles); no Microsoft asset | Same as above. |

The OneDrive and SharePoint tiles are original AI KB artwork, not Microsoft marks, so the verbatim-copy rule above does not apply to them.

The other marks here predate this file and came with the upstream tree.
